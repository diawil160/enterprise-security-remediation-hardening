# 🛡️ Enterprise Security Remediation & Hardening

This project was a multi-week group cybersecurity remediation project focused on identifying and correcting security weaknesses across Windows Server, Linux, and pfSense environments.

The team worked through findings from a security audit and implemented remediation measures involving system hardening, access control, identity and account management, firewall administration, auditing, and secure authentication.

## 👩🏽‍💻 My Contribution

My assigned portion of the project was **Week 2 – Access Control Remediation**. I performed hands-on remediation across Windows Server, Ubuntu Linux, and pfSense environments.

My responsibilities included:

- Reviewing and correcting Windows network share permissions
- Implementing group-based access controls for departmental resources
- Configuring Windows security settings through Group Policy
- Managing Linux users and group memberships
- Configuring Samba share permissions
- Restricting root access through SSH
- Configuring pfSense administrative access controls
- Creating and configuring administrative accounts
- Validating configuration changes through testing and screenshots

I also assisted team members with troubleshooting during later phases of the project, including helping resolve pfSense connectivity and administrative access issues.

## 🔐 Access Control Remediation

### Windows Server

Windows Server remediation focused on strengthening access to shared resources and reducing unnecessary exposure of user information.

Tasks included:

- Reviewing network share configurations
- Correcting departmental share permissions
- Verifying NTFS and share-level access
- Configuring Group Policy security settings
- Validating applied configuration changes

### Linux

Linux remediation focused on securing shared resources and administrative access.

Tasks included:

- Managing users and security groups
- Assigning users to appropriate departmental groups
- Updating Samba share configurations
- Restricting access based on group membership
- Disabling root SSH access
- Verifying configuration changes through the command line

### pfSense

pfSense remediation focused on protecting firewall administration and limiting access to authorized users.

Tasks included:

- Restricting access to the pfSense administrative interface
- Configuring administrative user accounts
- Strengthening administrative access controls
- Configuring secure management access
- Testing and validating access after remediation
